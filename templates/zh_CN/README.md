# 中文规则模板

模板是起点，不是成品。复制到文章同目录、改名 `rule.toml`，再按当前文章改 `[target]` 和具体规则——模板里的受众画像是示意，直接套用会让评分失去意义。

| 模板 | 适用场景 | 核心防线 |
| --- | --- | --- |
| `health-science.toml` | 患者/家属向健康科普 | 疗效承诺、恐吓、替代药物、伪科学 |
| `science-explainer.toml` | 普通读者的科学解释 | 相关当因果、夸大、术语不解释 |
| `product-review.toml` | 消费品评测与选购 | 隐瞒利益、假实测、只夸不批 |
| `tutorial-guide.toml` | 安装配置与上手教程 | 跳步、不可执行、版本不明 |
| `opinion-piece.toml` | 时评与议论文 | 稻草人、人身攻击、事实判断混写 |
| `news-report.toml` | 事件报道与采访 | 未核实当事实、标题党、单一信源 |
| `code-review.toml` | PR 与代码片段审查 | 硬编码密钥、吞错误、资源泄漏 |

英文原版在上一层目录，文件名一一对应，测试会校验两套目录保持同步。

过滤器是可选的选段脚本。`code-review.toml` 内置一个：只保留代码围栏里的内容，让规则审代码而不是审围栏外的说明。文字类模板默认不带过滤器；源文件是 Markdown 时，可以加一条指向 `filters/markdown.py` 的过滤器，或把同样的脚本内联进去。

## 使用

```text
ype_check(rule: "rule.toml", path: "final.md")
```

规则文件里的每条 LLM 规则都会单独开一个评分会话，模板默认每条 1 个会话（`llm = 1`）。确认规则有效后，再给关键规则加副本（`llm = 2`）降低方差。

## 改模板的优先级

1. 先改 `[target]`：受众和反受众决定"迎合指数"，也决定评分会话怎么理解文章；
2. 再删规则：模板里用不上的规则删掉，规则越少越准；
3. 最后改脚本阈值：段落长度、字数这类硬指标按发布渠道调整（手机上读的段落要更短）。
